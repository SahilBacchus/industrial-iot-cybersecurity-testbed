# Install Suricata

## 1. Install

Add the official OISF (makers of Suricata) stable repository:
```bash
sudo add-apt-repository ppa:oisf/suricata-stable
```

Update local package index: 
```bash
sudo apt update
```

Install suricata:
```bash
sudo apt install suricata -y
```

---

## 2. Verify Installation

Check the installed build info:
```bash
suricata --build-info
```

Validate the configuration file structure: 

```bash
sudo suricata -c /etc/suricata/suricata.yaml -T -v
```

---

## 3. Enable the Service

Enable Suricata to automatically start on boot: 
```bash
sudo systemctl enable suricata
```

Start the Suricata service:
```bash
sudo systemctl start suricata
```

Check that the service is active and running without errors: 
```bash
sudo systemctl status suricata
```

---

## 4. Monitor Live Alerts

View real-time intrusion detection alerts generated by Suricata: 
```bash
sudo tail -f /var/log/suricata/fast.log
```
