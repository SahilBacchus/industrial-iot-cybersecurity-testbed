
# ICMP Flood Attack Simulation (`icmp_flood.sh`) Guide

## Network Layer & Technical Context

- **OSI Layer:** **Layer 3 (Network Layer)**
- **Protocol:** **ICMP (Internet Control Message Protocol)**
- **Overview:** An ICMP Flood is a Denial of Service (DoS/DDoS) technique that overwhelms a target host with ICMP Echo Request ("ping") packets. When the target is configured to respond to ICMP Echo Requests, it processes the incoming requests and generate ICMP Echo Replies in response. A sufficiently large volume of requests can consume network bandwidth and processing capacity, potentially causing severe latency or reduced availability for legitimate traffic. The actual impact depends on factors such as the target's network capacity, firewall configuration, ICMP handling, and rate limiting.


---

## Execution Instructions

### 1. Make the Script Executable

Before running the shell script, ensure execute permissions are set:

```bash
chmod +x icmp_flood.sh
```

 ### 2. Run the Script

The script requires superuser privileges to craft raw ICMP sockets using `hping3`:

```
sudo ./icmp_flood.sh
```

 ## Interactive Prompts & Configuration Options

 When executing `icmp_flood.sh`, the interactive wizard will prompt you for configuration choices.

 ### Prompt Steps

 ### 1 Target IP Choice

 **Script Prompt:**

 `Use default target IP (192.168.0.122)? (y/n):`

 **Recommended Input:**

 `y` _(or `n` to enter a custom IP address)_

 **Configuration Details & Impact:**

 Selects the target device. Choosing `y` targets the Edge Server (`192.168.0.122`).

 - If `y` is selected, the script sets `TARGET_IP` to the default target IP.
- If `n` is selected, the script proceeds to Step 2 and prompts for a custom target IP address.

---

 ### 2. Custom IP Address _(if `n` is selected in Step 1)_

 **Script Prompt:**

 `Enter custom target IP address:`

 **Recommended Input:**

 `<target_ip>`

 **Configuration Details & Impact:**

 Specify an alternative target IP address on the local network.

 - This step is only displayed when `n` is selected in Step 1.
- The entered address is assigned to `TARGET_IP`.
- If no IP address is entered, the script exits.

---

 ### 3. Traffic Mode

 **Script Prompt:**

 `Select Traffic Mode:`

 - `1) High-Speed Traffic (--flood)`
- `2) Fast Interval Traffic (-i u1000)`

 **Recommended Input:**

 `1` or `2`

 **Configuration Details & Impact:**

 Controls packet generation rate:

 - **Option 1 (`--flood`):** Sends ICMP packets as fast as possible without displaying incoming replies.
- **Option 2 (`-i u1000`):** Sends approximately 1 ICMP packet every 1,000 microseconds (approximately 1,000 packets/sec).

---

 ### 4. Source IP Mode

 **Script Prompt:**

 `Source IP Configuration:`

 - `1) Simulate single host DoS (use my real IP address)`
- `2) Simulate DDoS, spoof source IP randomly (--rand-source)`

 **Recommended Input:**

 `1` or `2`

 **Configuration Details & Impact:**

 Configures the source IP address used in generated packets:

 - **Option 1 (Real IP):** Uses your host's actual IP address to simulate a single-source DoS attack.
- **Option 2 (`--rand-source`):** Randomizes the source IP address for generated packets, simulating traffic that appears to originate from multiple source addresses while still being generated by the same host.

---

 ### 5. Test Duration

 **Script Prompt:**

 `Enter test duration in seconds (or type 0 for indefinite run):`

 **Recommended Input:**

 `60` _(or desired duration)_

 **Configuration Details & Impact:**

 Defines the run time in seconds.

 - `60` runs the test for 1 minute.
- `0` runs the test indefinitely until stopped with `Ctrl+C`.

---

 ### 6. Execution Confirmation

 **Script Prompt:**

 `Proceed with execution? (y/n):`

 **Recommended Input:**

 `y`

 **Configuration Details & Impact:**

 Final confirmation prompt before executing `hping3`.

 - Choosing `y` starts the ICMP traffic test using the selected configuration.
- Choosing `n` aborts execution and exits the script.
