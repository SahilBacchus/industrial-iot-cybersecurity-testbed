# TCP SYN Flood Attack Simulation (`syn_flood.sh`) Guide

## Network Layer & Technical Context

* **OSI Layer:** **Layer 4 (Transport Layer)**

* **Protocol:** **TCP (Transmission Control Protocol)**

* **Overview:** A TCP SYN Flood is a Denial of Service (DoS/DDoS) technique that exploits the standard TCP three-way handshake (`SYN` -> `SYN-ACK` -> `ACK`). The attacker sends a high volume of TCP `SYN` packets to a target port. When the target receives these requests, it allocates connection resources and responds with `SYN-ACK` packets, leaving connections in a half-open state while waiting for final `ACK` responses that never come. A sufficiently large volume of requests can exhaust memory or saturate the target's TCP connection backlog, potentially preventing legitimate clients from establishing new connections. The actual impact depends on factors such as target system resources, TCP stack hardening, SYN cookies, firewall configuration, and rate limiting.

## Execution Instructions

### 1. Make the Script Executable

Before running the shell script, ensure execute permissions are set:

```bash
chmod +x syn_flood.sh

```

### 2. Run the Script

The script requires superuser privileges to craft raw TCP sockets using `hping3`:

```bash
sudo ./syn_flood.sh

```

## Interactive Prompts & Configuration Options

When executing `syn_flood.sh`, the interactive wizard will prompt you for configuration choices.

### Prompt Steps

### 1. Target IP Choice

**Script Prompt:**

`Use default target IP (192.168.0.122)? (y/n):`

**Recommended Input:**

`y` *(or `n` to enter a custom IP address)*

**Configuration Details & Impact:**

Selects the target device. Choosing `y` targets the Edge Server (`192.168.0.122`).

* If `y` is selected, the script sets `TARGET_IP` to the default target IP (`192.168.0.122`).


* If `n` is selected, the script proceeds to Step 2 and prompts for a custom target IP address.



---

### 2. Custom IP Address *(if `n` is selected in Step 1)*

**Script Prompt:**

`Enter custom target IP address:`

**Recommended Input:**

`<target_ip>`

**Configuration Details & Impact:**

Specify an alternative target IP address on the local network.

* This step is only displayed when `n` is selected in Step 1.


* The entered address is assigned to `TARGET_IP`.


* If no IP address is entered, the script exits.



---

### 3. Target Port Choice

**Script Prompt:**

`Use default target port (80)? (y/n):`

**Recommended Input:**

`y` *(or `n` to enter a custom port number)*

**Configuration Details & Impact:**

Selects the target TCP port. Choosing `y` targets HTTP port `80`.

* If `y` is selected, the script sets `TARGET_PORT` to the default target port (`80`).


* If `n` is selected, the script proceeds to Step 4 and prompts for a custom target port.



---

### 4. Custom Target Port *(if `n` is selected in Step 3)*

**Script Prompt:**

`Enter custom target port:`

**Recommended Input:**

`<target_port>` *(e.g., `8000` or `1883`)*

**Configuration Details & Impact:**

Specify an alternative target TCP port (e.g., HTTP ingestion server port `8000` or MQTT broker port `1883`).

* This step is only displayed when `n` is selected in Step 3.


* The entered port is assigned to `TARGET_PORT`.


* If no port is entered, the script exits.



---

### 5. Traffic Mode

**Script Prompt:**

`Select Traffic Mode:`

* `1) High-Speed Traffic (--flood)`

* `2) Fast Interval Traffic (-i u1000)`


**Recommended Input:**

`1` or `2`

**Configuration Details & Impact:**

Controls packet generation rate:

* **Option 1 (`--flood`):** Sends TCP SYN packets as fast as possible without displaying incoming replies.


* **Option 2 (`-i u1000`):** Sends approximately 1 TCP SYN packet every 1,000 microseconds (approximately 1,000 packets/sec).



---

### 6. Source IP Mode

**Script Prompt:**

`Source IP Configuration:`

* `1) Simulate single host DoS (use my real IP address)`

* `2) Simulate DDoS, spoof source IP randomly (--rand-source)`


**Recommended Input:**

`1` or `2`

**Configuration Details & Impact:**

Configures the source IP address used in generated packets:

* **Option 1 (Real IP):** Uses your host's actual IP address to simulate a single-source DoS attack.


* **Option 2 (`--rand-source`):** Randomizes the source IP address for generated packets, simulating traffic that appears to originate from multiple source addresses while still being generated by the same host.



---

### 7. Test Duration

**Script Prompt:**

`Enter test duration in seconds (or type 0 for indefinite run):`

**Recommended Input:**

`60` *(or desired duration)*

**Configuration Details & Impact:**

Defines the run time in seconds.

* `60` runs the test for 1 minute.


* `0` runs the test indefinitely until stopped with `Ctrl+C`.



---

### 8. Execution Confirmation

**Script Prompt:**

`Proceed with execution? (y/n):`

**Recommended Input:**

`y`

**Configuration Details & Impact:**

Final confirmation prompt before executing `hping3`.

* Choosing `y` starts the TCP SYN traffic test using the selected configuration.


* Choosing `n` aborts execution and exits the script.
